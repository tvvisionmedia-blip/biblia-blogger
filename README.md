# Versículos emergentes para Blogger

Muestra el texto de cualquier cita bíblica (ej. Juan 3:16) en una ventana emergente.
Texto: Reina-Valera 1960. © Sociedades Bíblicas en América Latina; publicar solo con su permiso.

Código para pegar en un gadget HTML/JavaScript de Blogger (cambia TU-USUARIO):

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/TU-USUARIO/biblia-blogger@main/versiculos.css">
<script src="https://cdn.jsdelivr.net/gh/TU-USUARIO/biblia-blogger@main/versiculos.js" defer></script>
```
